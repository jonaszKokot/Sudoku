# Sudoku

Webowa implementacja klasycznej gry logicznej Sudoku dostępna w przeglądarce. Projekt skupia się na implementacji logiki gry w czasie rzeczywistym, weryfikacji poprawności reguł oraz responsywnym interfejsie użytkownika.

🔗 **Wersja Live:** [jonaszkokot.github.io/Sudoku](https://jonaszkokot.github.io/Sudoku/)

## 🎮 O projekcie
Gracz ma za zadanie wypełnić siatkę o wymiarach 9x9 cyframi od 1 do 9 w taki sposób, aby żadna cyfra nie powtarzała się w tym samym wierszu, kolumnie ani w obrębie wydzielonych podkwadratów 3x3. Gra jest w pełni grywalna bezpośrednio w oknie przeglądarki.

## ✨ Funkcjonalności
- Grywalna siatka Sudoku z intuicyjnym wprowadzaniem cyfr
- Walidacja poprawności wprowadzonych wartości (wiersze, kolumny, bloki 3x3)
- Automatyczne sprawdzanie warunku wygranej po uzupełnieniu planszy
- Responsywny design dostosowany do różnych rozdzielczości ekranu
- Hostowanie bezserwerowe za pomocą GitHub Pages

## 🛠️ Technologie i narzędzia
- Technologie webowe: HTML5, CSS3, JavaScript
- Hosting i wdrożenie: GitHub Pages
